# Count1 original-invocation SSBO proof

This private, offscreen fixture keeps the unchanged, pinned original fragment
shader on a separate count3 layout. It compares that original GPU output and its
canonical array3 SSBO record with two explicitly specialized count1 interfaces:
pixel `(0, 0)` and the first actually rasterized invocation. Both retain one
color attachment and an owned 128-byte Set1 record, including atomic first claim.

The runner derives a temporary reusable helper include from the approved SSBO
fixture, excluding its old `main`. Only the owned test's descriptor declaration
and writes change to count1. The original shader never runs against that layout.
Every original/candidate color word and all 32 SSBO words must be bit-identical;
the existing resource/record canaries also remain active. Both Intel and lavapipe
must finish with validation and synchronization validation enabled and no errors.

```sh
python3 -B tests/native-fragment-count1-ssbo-gpu/run.py \
  --original /private/distort_ps_achromatic_se2.spv \
  --record /private/exclusive-count1-receipt.json --driver both
```

Set `VK_LAYER_PATH` and `LD_LIBRARY_PATH` to the explicitly inspected private
Khronos validation package when the host does not provide it. No system install
is required. The subprocesses are bounded and reaped before their temporary
compile products are removed; preserve the JSON receipt and use the main
project's `cleanup_completed_run(..., process_reaped=True)` completion hook for
any surrounding project test run.

The cold C++ transformer in `layer/pixel_ssbo_profile_transform.h` independently
produces these exact artifacts from successful native shader callback bytes.
It distributes only the observer's generated additions and scalar patch offsets,
not the original shader body. The optional journal pending mode retains early
native count1 layouts as non-ready facts until these actual generated bytes
verify a `ProbeInterface`; promotion keeps their original lifecycle generations.

These are source/host-GPU facts. They establish neither native creation/lifetime
compatibility nor same-draw physical-eye/video-frame association. They authorize
no receiver installation, native shader override, or passthrough activation.

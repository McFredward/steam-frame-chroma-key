# README artwork

- `steam-link-icon.png`: Valve's unmodified Steam Link app icon from the
  [official mobile apps page](https://store.steampowered.com/mobile/?l=english&show=steamapp),
  [original PNG](https://store.fastly.steamstatic.com/public/images/mobile/steam_link_icon.png).
  Retrieved 2026-10-17.
- `steam-frame-logo.svg`: Valve's Steam Frame wordmark, reused from GloomhavenVR's
  documented original, published by KOMODO and recorded on
  [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Steam_Frame_colored_logo.svg)
  ([original SVG](https://upload.wikimedia.org/wikipedia/commons/f/f3/Steam_Frame_colored_logo.svg)).
  `steam-frame-logo-dark.svg` keeps its geometry and blue, using white ink for
  dark backgrounds. Both match the files already used in GloomhavenVR.
- `flag-en.png` and `flag-de.png`: existing GloomhavenVR language-selector images,
  reused unchanged for the same English/German navigation.

The Steam Link and Steam Frame marks identify the supported products. They are
Valve trademarks, not this project's logo or a claim of Valve endorsement. The
project's source-code license does not grant rights to those trademarks.

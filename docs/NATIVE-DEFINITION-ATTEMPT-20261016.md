## Change of approach

There is still **no working streamed passthrough**. Receiving source pixels and
recognizing an offline pattern are earlier milestones, not an alpha presenter.
The maintainer explicitly rejected endless small diagnostic rounds. Before
requesting another hardware action, compose and check the remaining owned
offscreen output path, audit native lifetime/state-restoration admission, and
identify all native-only unknowns together. An unrelated unknown feature must
not hide every later observation and force one headset round per input.

The remaining native facts include the full actual compatible layout/creation
profile, same-invocation packed coordinate/source association, its physical-eye
route and safe original-state/lifetime binding. Offline affine fixtures must
not stand in for those native proofs. The next hardware request must name the
specific unresolved boundary and its decisive success/failure result; it must
not promise visible MR before that output is actually prepared.

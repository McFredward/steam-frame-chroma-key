# Same-invocation receiver integration

This is development of the receiver component for GloomhavenVR's streamed
explicit-opacity path. It does not enable live passthrough. GloomhavenVR677's
manual source-pattern setting remains unchanged; the native Steam PC sender is
not modified. The Frame remains restored until a specific new package and its
restart receive permission.

## Why the isolated proofs were insufficient

Actual retained native evidence differs from the smallest GPU fixtures:

- The decoded image's original binding9 layout has count1. The pinned original
  fragment declares an array3 even though its two accesses use constant0.
  Vulkan validation rejects the unmodified array3/count1 pairing. Static index0
  is not permission to relax the descriptor interface contract.
- An archived actual `PS_DISTORT` uses `vkCmdDrawIndexed`, after preceding
  `PS_MAIN` draws in the same primary command buffer. A one-direct-draw filter
  would reject this legitimate native recording.
- A later final-draw acquisition has selected draw ordinal4. Command buffers
  are reusable; the first stored SSBO record cannot simply be joined with a
  later replay's copied source image.
- Actual fragment storage is enabled, but the initial cold definition profile
  stopped at the original timeline-semaphore feature. This was our observer's
  refusal, not a failed native device creation.

The retained native-shape assessment is in private
`build/private-premultiplied-output-20261016/native-transaction-profile-assessment.json`.

## Integration contracts

An explicit owned count1 specialization preserves both original image accesses
and the complete original color expression. A cold C++ transformer generates
the pinned observer from the actual original shader consumed by the native
create callback. Only owned added instructions are distributed; the original
shader body is not embedded in the repository. The original array3 API stays
strict. Early count1 layout definitions remain non-operational facts until the
actual observer bytes authorize their interface.

The live tracker associates journal identities with the original successful
native pipeline creation, including the creation-time Core layout and Set0
generations. Those counters belong to different namespaces; raw handles or
numerically equal generations are not an association. Default-empty private
recording and target tickets are minted and consumed synchronously in the
original Begin/draw callbacks, never queued to a background thread.

The transaction owns its clone, descriptor suffix and 128-byte record. It resets
that record on the GPU inside the original recording, preserves preceding
ordinary draws and invokes the exact original direct or indexed draw once.
The original graphics pipeline is restored immediately. Unknown routes or later
draws invalidate publication without suppressing the original draw.

An owned marker follows the untouched original submit on the same externally
synchronized queue. Bounded ordinary batches and a canonical timeline submit
extension are admitted only with one occurrence of the selected command buffer.
The source-copy execution count and the observer marker count remain independent
and must agree, with exact command/pool generations and image/view/memory cohort.
GPU completion and successful retirement of the old reusable generation are
both required before publishing either result.

The receiver selects the separately pinned `Sparse32` profile: only a fragment
on the 32-by-32 pixel grid attempts the shared atomic claim. It means the first
eligible rasterized grid invocation, not a known physical-eye pixel. No eligible
invocation produces an unclaimed record and refuses publication. Both earlier
pixel0 and unrestricted first-covered profiles remain byte-identical for their
own proofs; unrestricted full-frame election is not the receiver default.

This change follows an actual minimal Intel GPU measurement: at 2304-by-2304,
the uninstrumented draw took 2.264 ms, unrestricted atomic election 13.784 ms,
and sparse election 2.270 ms. These are host GPU timings, not Frame estimates.
Separate original-shader GPU controls on Intel and lavapipe preserve both the
original color and full sparse record; a real rendered nongrid pixel preserves
the original color while leaving the entire record unclaimed. Source, timings,
validation and cleanup receipts remain in private
`build/private-first-covered-cost-20261016/`.

Idle alone never means recording retirement. At the original synchronized
`vkDestroyDevice` boundary, actual idle/device loss allows terminal retirement
and destruction of the observer's owned children before forwarding destruction.
These lifetime requirements follow the public
[device](https://docs.vulkan.org/refpages/latest/refpages/source/vkDestroyDevice.html)
and [pipeline](https://docs.vulkan.org/refpages/latest/refpages/source/vkDestroyPipeline.html)
destruction contracts.

## Evidence and remaining boundary

The two host GPU drivers retain bit-identical original color and full observer
records for both count1 modes. Separate composed-output proofs cover overlapping
glass and additive emission, including RGB at alpha0. Straight and premultiplied
input conventions are explicit; no native or game convention is inferred.

The new live-tracker bridge passes 162 focused CPU controls and ASan/UBSan.
The integrated receiver passes 281 private callback controls normally and with
ASan/UBSan, including preceding empty direct/indexed calls and legal reusable
command buffers. These use a finite fake dispatch, not a GPU. Three actual
host-loader controls additionally verify unarmed, armed and statistics-query
operation with the optional receiver linked. The unchanged default must reject
its new progress event unless that option is explicitly selected by the harness.
The first optional-loader attempt correctly failed on that unrecognized event;
the explicit profile now validates it rather than weakening the default check.
Cold-profile, factory, transaction and GPU evidence is retained privately under
`build/private-count1-ssbo-20261016/`,
`build/private-draw-transaction-worker-20261016/`,
`build/private-native-bridge-20261016/` and
`build/private-premultiplied-output-20261016/`.
The assembled callback source and loader/build evidence live in
`build/private-native-receiver-bridge-20261016/` and
`build/private-native-transaction-integration-20261016/`.
Small repairs reuse passing evidence for unchanged areas, not a claimed new
complete gate. Completed compiler caches and worker checkouts are removed while
originals, captures, failures, source pins and receipts remain.

These are software/host-GPU proofs. Actual native clone admission, observed
same-invocation values, their changing-source chart/eye/ray association, the live
alpha presenter and real game-coverage exporter still need completion. No
timestamp, private token, owned output fixture or successful compiler run grants
those rights. Another headset request must concern a coherent reviewed package,
not one more disconnected measurement. No automatic rollback timer or restart
is introduced.
